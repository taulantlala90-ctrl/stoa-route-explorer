How this is counted

Each successful swap emits a Routed event from the Stoa router. The dashboard requests the complete event history from deployment to the latest block. Distinct senders use the indexed sender address. Each swap is counted once for the estimate: its USDG side where present, otherwise its ETH/WETH side at the current CoinGecko USD price, otherwise a token side at the current USD price from the deepest available Robinhood pair on DexScreener. Token decimals come from the chain. Unpriced swaps are excluded and counted above. Prices are current estimates, not historical execution values, and the estimate can differ from Stoa’s own figures. USDG-sided volume separately includes only swaps with USDG. No trades are made by this dashboard.
